# Atom Setup

Редактор проектов TOML и компилятор автономных установщиков для Windows x64 от **Atomfren Team**.

[Скачать актуальный выпуск](https://github.com/Atomfren/AtomSetup/releases/latest)

1. Скачайте ZIP из раздела **Assets** и распакуйте его.
2. Откройте `atom-studio.exe`, затем проект `examples/setup.toml`.
3. Нажмите **«Собрать EXE»**. Путь к установщику появится в журнале сборки.

`atom-pack.exe` позволяет собирать те же проекты из терминала и CI. Документация, пример и уведомления о сторонних компонентах входят в ZIP.

В следующем этапе — учёт установленных файлов и обновления с сохранением пользовательских данных. Дальше — подпись, автоматизация выпуска и импорт основных секций Inno Setup.
